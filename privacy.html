プライバシーポリシー

制定日：2026年10月28日

1. 対象

本ポリシーは、運営者が個人で使う YouTube 予約投稿ツール（以下「本アプリ」）に適用されます。本アプリの利用者は運営者本人のみです。

2. 取得する情報

本アプリは Google の OAuth 認証により、YouTube Data API へのアクセス権（動画のアップロードと、自分のチャンネル情報の確認）を取得します。認証情報は運営者のパソコン内にのみ保存されます。

3. 利用目的

取得した情報は、運営者自身のチャンネルへ動画をアップロード・予約公開するためだけに使います。

4. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。広告や分析目的にも使いません。

5. 削除

運営者はいつでも Google アカウントの「サードパーティ アクセス」から本アプリのアクセス権を取り消し、保存した認証情報を削除できます。

6. Google API サービスの利用

本アプリによる Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

English summary: This app is a personal tool used only by its operator. It uses Google OAuth to upload and schedule the operator's own videos on the operator's own YouTube channel. Credentials are stored only on the operator's computer. No data is shared with, sold to, or used by third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
